# EduMN - Монгол онлайн сургалтын платформ

Admin/Teacher/User эрхтэй, бүрэн ажиллагаатай онлайн сургалтын платформ.

## Эрхүүд

### 🔐 Админ (Admin)
- Нэвтрэх: `Admin` / `99033062`
- Багш нарыг нэмэх, хасах, зөвшөөрөх
- Мэдээ мэдээлэл нийтлэх, устгах
- Бүх сургалтуудыг удирдах

### 🎓 Багш (Teacher)
- Бүртгүүлэх хуудаснаас "Багш" сонгож бүртгүүлнэ
- Админ зөвшөөрсний дараа нэвтрэх боломжтой
- Хичээл нэмэх (төлбөртэй/төлбөргүй)
- Профайл зураг солих

### 🧑 Суралцагч (User)
- Бүртгүүлэх хуудаснаас "Суралцагч" сонгож бүртгүүлнэ
- Сургалт үзэх, бүртгүүлэх
- QPay-ээр төлбөр төлөх
